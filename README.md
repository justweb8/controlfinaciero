# Control Financiero — PWA

Sistema de control financiero para constructora.

## Archivos
- `index.html` — App principal
- `manifest.json` — Configuración PWA
- `sw.js` — Service Worker (modo offline)
- `logo-full.png` — Logo del sistema
- `icon-192.png` / `icon-512.png` — Íconos de app
- `icon-maskable-512.png` — Ícono adaptable Android
- `apple-touch-icon.png` — Ícono iOS
- `favicon.png` — Favicon navegador

## Despliegue en GitHub Pages
1. Sube todos estos archivos a un repo en GitHub
2. Ve a Settings → Pages → Branch: main → Save
3. Tu app estará en: https://tuusuario.github.io/nombre-repo
